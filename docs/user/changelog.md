# 省心PPT 更新日志

> **版本**: v10.100.0

## v10.100.0 (2026-07-28)

### 🛡️ 短信验证码可靠性与可追踪性升级

- 登录、找回密码和换绑手机号统一为“先保存挑战、后请求供应商”，避免供应商已受理但应用侧超时后验证码失效。
- 新验证码使用应用生成的固定验证码和本地安全校验，消除验证码校验阶段再次依赖外部短信 RPC 的单点故障；兼容存量远端验证码记录。
- 供应商网络超时会明确返回“提交状态未知”，保留验证码供已收到短信的用户继续验证，并禁止自动重发造成重复短信。
- 调整共享网络下的短信限流，并为限流数据库异常提供保守本地兜底，减少客户共享出口被误伤。
- 增加不含完整手机号和验证码的逐笔发送审计，可关联应用请求、阿里云请求号和回执业务号。

## v10.99.1 (2026-07-14)

### 🐛 验证码真实发送链路修复

- 修正 v10.99.0 只用 HEAD 检查阿里云入口、未覆盖真实签名 RPC 请求的验收缺口。
- 阿里云 RPC 改用官方支持的 GET 签名请求，避开 Vercel 到 DYPNS 的空 body POST 长连接超时。
- 供应商请求超时上限调整为 20 秒，仍禁止模糊超时自动重发，避免重复短信。
- 生产就绪检查现在执行不发送短信的签名验证码核验请求，同时验证网络、签名、AccessKey 与产品权限。

---

## v10.99.0 (2026-07-14)

### 🐛 登录验证码可靠性修复

- 修复 Vercel 香港函数冷启动后，阿里云旧 SDK 传输层连接超时导致验证码发送失败的问题。
- 登录、密码重置及短信健康检查固定到实测可达的东京节点，生成与下载区域保持不变。
- 阿里云验证码改用官方 RPC 签名协议和平台原生网络传输，避免旧 `httpx` 连接层反复超时。
- 短信供应商连接失败时，跨实例数据库限流额度现在会真实回滚，不再把网络故障误报为“请60秒后再试”。
- 分布式限流改为并发安全的预留/释放机制，拒绝请求不再污染计数。
- 保留手机号与 IP 双重防轰炸策略；阿里云真实频控仍按其返回等待时间执行。

## v10.98.0 (2026-07-14)

### ✅ 商业化可靠性升级

- 为所有请求补充全链路请求标识、结构化脱敏日志、依赖就绪检查和运维告警能力。
- 生成任务增加短期幂等控制、重复请求恢复、失败重试和全局预算保护；仅保存任务控制元数据，不保存用户内容或生成文件。
- 增加生成总开关、维护模式、灰度比例和每日全局限额，支持故障止损与分批放量。
- 增加数据库恢复就绪检查、商业化预检、覆盖率门禁和两个浏览器断点恢复回归流程。
- 增加可选隔离恢复快照验证和部署后健康/Cron 验收命令；外部告警与隔离恢复演练暂不作为上线门禁。
- 保持既有下载、R2 加速、生成历史与产物交付逻辑不变；附件即时删除，异常遗留由后续上传触发的机会式清理与每日定时任务兜底。
- 补充隐私政策、服务条款、支持入口及商业化运维手册。

### 📌 产品边界

- 本版本不调整下载与历史业务逻辑，不删除既有文件对象或记录。
- 不提供用户数据导出能力；真实支付链路已完成业务验收。
