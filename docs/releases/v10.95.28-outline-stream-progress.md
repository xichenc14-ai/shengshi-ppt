# v10.95.28 - 大纲生成流式进度与低思考优化

## 修复

- 修复大纲生成阶段长时间停在 44%/45%，用户误以为页面卡死的问题。
- 修正“流式连接波动，正在切换稳态生成...”提示，并减少无意义重复等待。
- `/api/outline/stream` 增加 heartbeat 事件：LLM 尚未返回时持续推送阶段说明、耗时和进度。
- 流式接口运行时长调整为 180 秒，避免 60 秒截断后前端再重复发起稳态请求。

## 性能

- 大纲任务默认使用更低温度 `0.35`，减少发散与生成耗时。
- MiniMax M3 大纲任务显式设置 `thinking: {"type":"disabled"}`，降低延迟。
- 大纲 fallback 策略改为主模型快速尝试一次，再切备用模型，避免同一模型多次长重试。

## 体验

- 前端支持消费 heartbeat，等待期间动态展示“正在提炼主线 / 匹配图表图标 / 检查页数逻辑”等过程状态。
- 进度展示阶段上限从 44% 优化为更平滑的阶段推进。

## 验证

- `npx tsc --noEmit`
- `npm test -- --run`
- `npm run build`
- 本地浏览器打开首页，无控制台错误
