# v10.95.27 - 验证码登录远端校验修复

## 修复

- 修复阿里云 DYPNS 验证码发送成功但未返回真实 `VerifyCode` 时，系统写入随机本地备用码导致用户收到验证码与数据库验证码不一致的问题。
- 发送验证码未返回真实码时，改为写入远端校验标记，并在登录校验阶段调用阿里云 `CheckSmsVerifyCode` 验证用户输入。
- 同步修复更换手机号验证码链路，避免同一问题在账号换绑场景复发。
- 将验证码有效期与短信模板提示统一为 5 分钟。

## 验证

- `npx tsc --noEmit`
- `npm test -- --run`
- `npm run build`
