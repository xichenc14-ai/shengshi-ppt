# v10.100.0 — 客户短信可达性修复

发布日期：2026-07-28

## 修复范围

- 共享移动网络、企业网络中的客户不再因单一 IP 的过严分钟阈值而普遍被拒绝。
- 分布式限流 RPC 瞬时异常降级为保守本地限流，不再把基础设施瞬断放大为全量短信失败。
- 三个验证码入口均在发送前创建本地挑战记录，供应商超时后仍允许用户使用可能已收到的验证码。
- 新挑战使用 HMAC 保存验证码，不保存明文；历史远端验证码记录仍可校验。
- 每次发送使用 `OutId` 与应用请求号关联，并写入不含完整手机号的审计记录。

## 上线顺序

1. 先执行 `supabase/migrations/20260728_sms_send_attempts.sql`。
2. 在 Vercel Production 配置独立的 `SMS_CODE_HASH_SECRET`。
3. 发布 v10.100.0，并检查 `/api/health/readiness` 与短信就绪检查。
4. 阿里云启用 HTTP 送达回执后，以 `OutId` / `BizId` 回填审计记录。

## 验收

- 自动化：全部测试、类型检查、生产构建通过。
- 线上：在真实客户网络各选一个号码完成“发送—接收—验证”闭环；遇到 HTTP 202 时，不重复发送，先使用已收到验证码。
