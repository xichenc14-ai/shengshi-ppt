# v10.97.0 — P0 商业化安全加固

发布日期：2026-07-12

## 范围

本版本只处理当前产品范围内的 P0 商业化风险。微信登录、图表/流程图编辑不属于当前产品范围，不纳入本版本验收。

## 已完成

- 旧 `/api/export` 在生产环境整体停用，并移除任意外部 URL 服务端代理能力，阻断 SSRF 与带宽滥用。
- `/api/ppt-local` 明确标记为实验接口，生产环境返回 410；开发模式不再接受客户端传入的 API Base/API Key。
- AI 大纲、Gamma 生成、图片理解、上传令牌、登录会话、注册短信、支付下单和支付回调接入 Supabase 原子跨实例限流。
- 生产环境的分布式限流配置或 RPC 异常时 fail-closed，不再静默降级为单实例内存限流。
- 新增完整商业化数据库基线与 `consume_rate_limit` RPC。
- 订单和会员权益遇到数据库字段缺失时，生产环境拒绝静默删除字段继续写入。

## 部署要求

部署应用前，必须先执行 `supabase-migrations/00-commercial-base-schema.sql`，再按编号执行后续迁移。未部署跨实例限流 RPC 时，关键生产接口会返回限流拒绝，这是预期的安全行为。
