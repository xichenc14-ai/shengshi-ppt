# v10.98.0 — 商业化可靠性与运营加固

发布日期：2026-07-14

## 产品边界

- 不提供用户数据导出。
- 上传附件仅用于本次解析，服务读取后立即删除。
- 本版本不改变既有下载、R2 加速、生成历史或产物交付业务逻辑，不删除已有对象和记录。
- 附件在读取后即时删除；异常遗留由后续上传触发的机会式清理与每日平台 Cron 兜底清理。
- 生成幂等能力仅保存短期任务控制元数据，不保存用户输入、附件或生成内容。
- 真实支付链路已由业务验收通过，本版本不重复改变支付方案。

## 已完成

- 请求链路统一注入请求 ID，核心生成、支付、回调、导出和健康检查输出结构化脱敏日志。
- 新增公开依赖就绪检查和受密钥保护的定时运维检查；外部 Webhook 或 Telegram 告警为可选能力。
- Gamma 生成增加短期幂等、重复请求恢复、失败重试和过期控制记录清理。
- 新增生成总开关、维护模式、灰度比例和每日全局调用限额。
- 新增商业核心表恢复就绪检查和恢复工具骨架；隔离恢复演练暂不作为本次上线门禁。
- 商业预检增加回归保护，确保既有下载加速、代理回退和生成历史业务链路不被本次加固改变。
- 补充隐私政策、服务条款和支持入口，明确第三方 AI 处理与安全边界。
- CI 增加覆盖率门禁和浏览器断点恢复回归；商业预检统一执行数据库、恢复、lint、覆盖率与生产构建检查。

## 发布验证

- 单元与 API 测试：43 个测试文件通过，217 项通过、1 项跳过。
- 覆盖率：Statements 30.19%、Branches 25.47%、Functions 36.41%、Lines 31.62%，全部高于门禁阈值。
- 生产构建：70 条应用路由完成类型检查和生产编译。
- 浏览器回归：大纲断点恢复、Gamma 生成断点恢复。
- 生产数据库：跨实例限流 RPC 与商业核心表可读检查。

## 部署后必须配置

- 设置高强度 `CRON_SECRET`。
- 确认 Vercel Cron 可调用 `/api/cron/operational-check`。
- 首次以较低 `GENERATION_ROLLOUT_PERCENT` 放量，并观察就绪检查、失败率和全局限额。

## 可选后续能力

- 如后续启用外部告警，再配置 Webhook 或 Telegram 并执行真实送达测试。
- 如后续建设隔离恢复环境，再执行恢复演练并记录恢复证据。
- 部署后执行 `npm run ops:postdeploy:check`，验证依赖健康和 Cron 鉴权；仅在已配置告警时测试告警送达。

以上项目依赖部署平台或隔离数据库权限，不应以代码测试结果替代。
