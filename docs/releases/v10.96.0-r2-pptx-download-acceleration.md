# v10.96.0 - R2 PPTX 下载加速

## 新增

- PPTX 下载链路接入 Cloudflare R2：首次从 Gamma 拉取成功后写入 R2，后续通过短期签名 URL 直连下载。
- 新增 `generation_artifacts` 元数据表，记录 `generationId`、文件格式、对象 Key、文件名、大小、sha256 与状态。
- 新增 `/api/artifacts/[id]/download` 下载入口，历史记录可直接复用已镜像的 artifact。

## 优化

- `/api/export-pptx` 优先命中 R2 artifact，未命中时自动镜像；R2 或数据库异常时回退原后端代理下载。
- 前端生成结果与历史记录下载链接统一走站内下载入口，减少 Gamma 临时链接过期和跨域下载波动。
- 环境模板、商业化环境检查脚本补充 R2 下载加速配置项。

## 运维

- 已创建并启用 R2 bucket `xinppt-artifacts`，生产环境变量已写入 Vercel Production。
- Supabase 远端已应用幂等迁移，补齐 `generation_artifacts`、`generation_history.artifact_id`、索引与 RLS 策略。
